Por favor, coloque aquí los archivos de activos que quiere que se sirvan estáticamente.

- logo.png  -> recomendado: 512x512 PNG o SVG exportado desde Figma / Illustrator
- hero.webp -> imagen de hero optimizada (webp)

Ruta pública desde la aplicación: /assets/<nombre-de-archivo>

Ejemplo: colocar el logo en `public/assets/logo.png` permitirá que la app lo cargue automáticamente.
